# XANAMI — сайт-витрина

Одностраничник для мастера по индивидуальному пошиву: каталог изделий, мерки,
доставка, FAQ и форма заявки, которая собирает сообщение для Telegram.

Стек: React 18 · Vite · Tailwind CSS 3 · lucide-react.

---

## Быстрый старт

```bash
npm install
npm run dev
```

Сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

## Информация

### Всё в одном файле

`src/data/content.js`:

| Что | Где |
|---|---|
| Telegram | `LINKS.tailor` (заказы), `LINKS.channel` (канал) |
| Калькулятор СДЭК | `CDEK_CALC` |
| Условия оплаты | `PREPAY.dresses`, `PREPAY.other` |
| Пункты меню | `NAV` |
| Категории | `CATEGORIES` |
| Каталог | `PRODUCTS` |
| Визитки | `FEATURED` |
| Мерки | `MEASUREMENTS`, `MEASURE_TIPS` |
| Доставка | `DELIVERY_STEPS`, `DELIVERY_FACTS` |
| Вопросы | `FAQ` |
| Тексты о бренде | `ABOUT` |

### Каталог: карточка изделия

```js
{
  id: "veil",                    // уникальный, используется в ссылках
  name: "Veil of Ash",
  category: "dresses",           // dresses | zip | denim
  kind: "Вечернее платье · корсет · фата",
  price: null,                   // null → «по запросу», число → «7 200 ₽»
  img: "/assets/hero_veil.jpg",
  gallery: ["/assets/...jpg"],   // дополнительные ракурсы
  photoStatus: "studio",         // "studio" | "reshoot"
  meta: "Бордо · кружево · фата",
  description: "…",
  size: "по вашим меркам",
}
```

- `price: 7200` → на карточке «7 200 ₽»
- `price: null` → «по запросу»
- `photoStatus: "reshoot"` → плашка «Фото обновляется»

### Замена фото

1. Положите файл в `public/assets/`, например `dress_new.jpg`.
2. В `content.js` укажите `img: "/assets/dress_new.jpg"`.

Доступные кадры: `hero_veil.jpg` (визитка), `couture_*` (платья),
`street_*` (зипки, джинсы, вторые ракурсы `*_back.jpg`).

### Каталог из Google Таблицы

Если заказчице удобнее вести ассортимент в таблице — она не будет трогать код.

1. Таблица с колонками в первой строке:
   `id, Название, Категория, Подзаголовок, Цена, Фото, Описание, Ткани, Фото-статус, Размер`
2. Файл → Поделиться → Опубликовать в интернете → CSV.
3. Вставить ссылку в `SHEET_CSV_URL` в `src/lib/sheet.js`.

Пока ссылка пустая — показывается локальный каталог. Если таблица недоступна,
сайт молча откатывается на `PRODUCTS`: ошибка не ломает страницу.

Фото в таблице можно указывать прямой ссылкой (`https://…`), тогда файлы
класть в проект не нужно.

## Форма заявки

Бэкенда нет — и это осознанно: не нужно хранить персональные данные и
отвечать за утечку. Поля складываются в текст:

```
Заявка с сайта XANAMI

Имя: Аня
Связь: @anya
Изделие: Veil of Ash
Размер / мерки: 88-68-96
Желаемый срок: к 20 декабря

Комментарий: …
```

и открывают `https://t.me/bogomol_004?text=…`. На десктопе Telegram подставит
текст в поле ввода, на телефоне — в системный шаринг.

Из карточки товара кнопка «Заказать» скроллит к форме и подставляет изделие.

Если позже понадобится приём заявок без Telegram (почта, CRM) — меняется
только `submit` в `OrderForm.jsx`.

## Что учтено из ТЗ

- Только авторские эскизы, без чужих референсов — отдельный вопрос в FAQ и
  пункт в блоке «О мастерской».
- Склада нет, «продано» не используется — статусы заменены на
  «Студийное фото» / «Фото обновляется».
- Оплата только в Telegram; на сайте ничего не списывается.
- Оплата: платья 50/50, повседневное 100% — в карточке товара, в блоке
  «Доставка» и в FAQ.
- Доставка СДЭК + калькулятор.
- Примерок нет — сказано в блоке мерок и в FAQ.
- Форма заявки — приоритет; Telegram остаётся альтернативой.

# 📖 Инструкция: Как управлять каталогом на сайте

Всё управление товарами на сайте происходит через Google Таблицу. Вам не нужно ничего программировать — просто заполняйте строки, а сайт будет обновляться автоматически.

## 1. Структура таблицы (Колонки)
В самой первой строке таблицы должны быть строго такие заголовки (их нельзя переименовывать или менять местами):

| id | Название | Категория | Подзаголовок | Цена | Фото | Галерея | Описание | Ткани | Фото-статус | Размер | Оплата |
|:---| :------- | :-------- | :----------- | :--- | :--- | :------ | :------- | :---- | :---------- | :----- | :----- |

*   **id** — уникальный код товара латиницей (например, `veil` или `zip-rose`). Если оставить пустым, сайт придумает его сам.
*   **Название** — имя изделия (например, *Veil of Ash*).
*   **Категория** — напишите одно из трех: `Платья`, `Зипки` или `Джинсы` (сайт сам распределит их по фильтрам).
*   **Подзаголовок** — краткое описание через точку (например, *Корсет · кружево · фата*).
*   **Цена** — впишите только число (например, `7200`). Если оставить пустым, на сайте напишется «по запросу».
*   **Фото** — ссылка на главное фото (обложку).
*   **Галерея** — ссылки на дополнительные фото.
*   **Описание** — подробный текст о товаре.
*   **Ткани** — материалы (например, *Бордо · чёрное кружево · фата*).
*   **Фото-статус** — напишите `studio` (будет плашка «Студийное фото») или `reshoot` (будет плашка «Фото обновляется»).
*   **Размер** — например, *по вашим меркам* или *S–L*.
*   **Оплата** — условия оплаты именно для этого товара (подробнее в п. 4).

---

## 2. Как добавлять фотографии (Важно!)

Сайт умеет работать с фотографиями напрямую из вашего Google Диска. Вам не нужно сжимать их или загружать на сторонние сайты.

### Шаг 1. Загрузите фото в Google Диск
Создайте папку на Google Диске и загрузите туда все фотографии товаров.

### Шаг 2. Откройте доступ
1. Нажмите правой кнопкой мыши на папку (или на конкретное фото) и выберите **«Поделиться»**.
2. В разделе «Общий доступ» нажмите **«Все, у кого есть ссылка»**.
3. Убедитесь, что справа выбрана роль **«Читатель»**. Нажмите «Готово».

### Шаг 3. Скопируйте ссылку
Нажмите на фото правой кнопкой мыши → **«Поделиться»** → **«Копировать ссылку»**. 
Ссылка будет выглядеть примерно так: 
`https://drive.google.com/file/d/1ApAQtR4-PqJNVJyZBQUalP2gcPnaX1sf/view?usp=sharing`

Эту ссылку можно просто вставить в колонку **«Фото»**. Сайт сам поймёт, что это Google Диск, и покажет картинку.

### Шаг 4. Несколько фото для одного товара
У вас есть два способа добавить несколько ракурсов:
*   **Способ А:** В колонку **«Фото»** вставьте несколько ссылок через запятую. Первая ссылка станет обложкой, а остальные автоматически попадут в карусель (галерею) на сайте.
*   **Способ Б:** Одну ссылку (обложку) вставьте в колонку **«Фото»**, а остальные ссылки через запятую — в колонку **«Галерея»**.

*(Подсказка: если хотите видеть превью картинки прямо в таблице, оберните ссылку в формулу: `=IMAGE("ссылка")`. Сайт всё равно считает её правильно).*

---

## 3. Важное правило про ссылки (Умные карточки)
Когда вы вставляете ссылку в ячейку, Google Таблицы могут автоматически превратить её в «умную карточку» (синенькую кнопку с иконкой). 
**Это может сломать загрузку фото на сайте.**
Если ссылка стала кнопкой — нажмите на неё правой кнопкой мыши и выберите **«Отменить преобразование в чип»** (или «Отменить умную карточку»). Ссылка должна остаться обычным текстом.

---

## 4. Как работают условия оплаты
В колонке **«Оплата»** вы можете написать индивидуальные условия для конкретного товара (например: *«100% предоплата»* или *«50% при заказе, 50% после фото»*). 

*   Если вы **заполнили** эту колонку — на сайте в карточке товара покажется именно ваш текст.
*   Если вы **оставили её пустой** — сайт применит стандартные правила из настроек (для платьев — 50/50, для остальных вещей — 100% предоплата).

---

## 5. Как обновляются данные на сайте
После того как вы что-то изменили в таблице:
1. Убедитесь, что таблица опубликована: **Файл → Поделиться → Опубликовать в интернете → CSV**.
2. Google обновляет данные не мгновенно. Изменения на сайте могут появиться в течение **3–5 минут**. Если фото или текст не обновились сразу — просто подождите и обновите страницу сайта.

**Ошибка никогда не сломает сайт.** Если вы случайно допустите ошибку в таблице, сайт просто покажет старую версию каталога, пока вы не исправите данные.
